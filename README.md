成語接龍遊戲
使用 tkinter 製作玩家對電腦的對戰遊戲

日期：	2026/11

研究動機
成語接龍是以前一個成語的最後一個字，作為下一個成語的第一個字，雙方輪流進行的文字遊戲。它很適合改寫成程式專題：規則清楚、資料量不大，卻同時包含字串處理、集合與字典、條件判斷、事件處理與介面設計等初學者必學的觀念。
學習Python初期，作業多半停留在命令列畫面。若能做出有按鈕、計分板與倒數計時的視窗，成就感會高出許多，也更接近日常使用的應用程式。因此本專題以 Python 內建的 tkinter 製作可與電腦對戰的成語接龍，並在基本功能完成後，逐步加入同音接龍與釋義顯示，讓遊戲兼具學習用途。
